# 00. 개요

> 군인 전법활동 봉사자 명부를 관리하는 내부용 웹 애플리케이션입니다.

- 운영 주소: 배포 후 결정
- 저장소 성격: 사내/부대 내부 관리 도구
- 현재 단계: 기초 CRUD + 대시보드 + Google 로그인까지 구현된 MVP

## 무엇을 하는가

봉사자의 기본 정보와 활동 상태를 한 곳에서 관리합니다.

- 봉사자 등록·수정·삭제
- 이름, 소속, 전문분야, 활동지역으로 검색
- 활동중 / 대기 / 휴면 상태 필터
- 상태별 편성 인원과 비율 확인
- 최근 등록 봉사자 확인
- 허용된 Google 계정만 접근

## 현재 구현 범위

| 구분 | 상태 | 설명 |
| --- | --- | --- |
| Google 로그인 | 구현됨 | OAuth 2.0 + PKCE, 허용 이메일 목록 |
| 세션 | 구현됨 | HMAC 서명 쿠키, 7일 |
| 봉사자 명부 | 구현됨 | 검색, 상태 필터, 정렬 |
| 봉사자 CRUD | 구현됨 | HTMX 모달 폼 |
| 대시보드 | 구현됨 | 상태별 편성, 최근 등록 |
| 반응형 UI | 구현됨 | 320px ~ 데스크톱 |
| 활동 일지 | 미구현 | `activities` 테이블 제안됨 |
| 상담 신청·배정 | 미구현 | `support_requests` 테이블 제안됨 |
| 공지·게시판 | 미구현 | `notices` 테이블 제안됨 |
| 권한 분리 | 미구현 | 현재는 허용된 사용자 모두 동일 권한 |
| 페이지네이션 | 미구현 | 조건에 맞는 전체 행을 렌더링 |

기능 우선순위와 상세 설계는 [10. 확장 가이드](10_extension-guide.md)를 참고하세요.

## 기술 스택

| 계층 | 선택 | 버전 | 역할 |
| --- | --- | --- | --- |
| 런타임 | Cloudflare Workers | Wrangler 4.158 | 서버 실행 |
| 프레임워크 | Hono | 4.13 | 라우팅, 미들웨어, JSX SSR |
| 뷰 | Hono JSX | - | 서버 렌더링 HTML |
| 상호작용 | HTMX | 2.0.11 | 부분 갱신, 모달, 삭제 |
| 스타일 | Tailwind CSS | 4.3 | 유틸리티 + `@theme` 토큰 |
| DB | Cloudflare D1 | - | SQLite 기반 관리형 DB |
| ORM | Drizzle ORM | 0.45 | 스키마, 쿼리, 마이그레이션 |
| 인증 | Google OAuth 2.0 | - | 로그인 |
| 언어 | TypeScript | 5.9 | strict 모드 |

Node.js 20 이상이 필요합니다. 로컬 개발은 Node.js + Wrangler로 진행하고, 배포는 Cloudflare Workers에서 실행됩니다.

## 용어

| 용어 | 의미 |
| --- | --- |
| 봉사자 | 군인 전법활동을 지원하는 사람. 현역, 예비역, 군무원, 민간 전문가 포함 |
| 편성 | 봉사자를 활동 상태별로 분류한 현황 |
| 활동중 (`active`) | 현재 활동 가능한 상태 |
| 대기 (`standby`) | 등록되었으나 활동을 기다리는 상태 |
| 휴면 (`inactive`) | 당분간 활동하지 않는 상태 |
| 신분 | 봉사자의 계급·신분. 예: `예비역 대위`, `군무원`, `민간 전문가` |
| HTMX 파셜 | 페이지 전체가 아니라 갱신에 필요한 HTML 조각 |

## 설계 원칙

1. **서버가 진실의 원천** — 화면 상태는 URL과 DB에서 결정합니다.
2. **작은 자바스크립트** — HTMX로 부분 갱신하고, 직접 작성한 JS는 모달·토스트·포커스 정도로 제한합니다.
3. **명시적인 HTTP 규약** — 성공 204 + 이벤트, 검증 실패 200 + 폼, 인증 만료 401 + `HX-Redirect`.
4. **내부 도구다운 밀도** — 카드 남발 대신 표와 규칙선으로 정보를 구조화합니다.
5. **기본은 닫힘** — 허용 이메일 목록이 비어 있으면 로그인을 거부합니다.
