# 03. 봉사자 명부 스프레드시트

> 원본: [Google 시트](https://docs.google.com/spreadsheets/d/10C3p8DWr0vTf_lapagfL-Fa8Pi4zuPiPc9-v6cTbQIU/edit?gid=523619722)
> 정리일: 2026-11-07

## 상태: 접근 불가

원본 시트가 **비공개**로 설정되어 있어 내용을 가져오지 못했습니다.

- `export?format=csv`, `gviz/tq`, `export?format=xlsx` 모두 `401` (Google 로그인 요구)
- 인증된 Google 세션이 이 환경에 없습니다.

## 확인이 필요한 것

- 시트의 컬럼 구성 (이름, 소속, 연락처, 활동 상태 등)
- 현재 관리 중인 봉사자 수와 상태 구분 기준
- 신청폼 응답 시트와 명부 시트가 같은 문서인지, 별도인지

## 접근 권한을 받은 뒤 할 일

1. 파일 → 다운로드 → CSV(또는 xlsx)로 내려받아 `refs/`에 둡니다. (개인정보가 있으므로 커밋하지 않도록 `.gitignore` 확인)
2. 컬럼을 `volunteers` 스키마와 대조해 매핑표를 만듭니다.
3. 필요하면 D1 이관용 스크립트 또는 `wrangler d1 execute --file`용 SQL을 생성합니다.

## 대안

- 시트를 "링크가 있는 모든 사용자(뷰어)"로 공유하면 위 URL로 바로 내려받을 수 있습니다.
- 또는 공유된 사본의 링크를 받아 동일한 방식으로 정리합니다.
- 민감 정보가 있으면 헤더만 캡처해 구조만 공유해 주셔도 스키마 정리에 충분합니다.
